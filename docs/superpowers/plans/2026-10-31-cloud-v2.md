# GreenCall Cloud v2 — Implementation Plan

> **For agentic workers:** Use superpowers:executing-plans with independent delegated implementation and a final fresh review. The owner's explicit autonomy mandate supplies the execution authorization.

**Goal:** Replace Cloud Stage1 placeholders with a protected, testable read path, improve the operational interface and correct forecast validation.

**Architecture:** Retain Node ESM, vanilla JS and local Plotly for functional parity and the Windows runner. Vercel handlers authenticate before accessing an immutable, validated Neon snapshot. Google remains the official read-only source; ingestion runs outside HTTP requests. The absence of credentials or a private snapshot is an explicit unavailable state.

**Tech Stack:** Node.js, Web Request/Response, HMAC sessions, existing Neon HTTP driver, PostgreSQL, existing analytics engine, Agent Browser.

**Spec:** AGENTS.md; docs/GREENCALL_VISION_FUNCIONAL.md; docs/GREENCALL_AUTONOMIA_Y_CALIDAD.md; docs/GREENCALL_MATRIZ_ACEPTACION.md.

## Global Constraints

- Branch codex/greencall-v2 starts at bc8429c on develop-cloud; preserve Stage1 and main.
- Google Sheets strictly read-only. No credentials, private snapshots or operational screenshots in Git or public deployments.
- Missing data/costs/metrics are never replaced with invented zeroes. Preserve historical source data and business rules.
- No production deployment or remote database mutation during this implementation.
- Manual routine upload remains physical-count Excel; legacy importers remain available as contingency.

## Review Focus

- Unauthenticated and misconfigured requests must fail closed before any data access.
- Expired/tampered cookies and cross-origin mutations must fail; credentials must never appear in responses.
- Empty, malformed, conflicting or privacy-unsafe snapshots cannot become the active dataset.
- Navigation must work without data, and small screens must have no accidental horizontal overflow.
- Forecast eligibility and metrics must use chronological training folds; incomplete months must not masquerade as full demand.
